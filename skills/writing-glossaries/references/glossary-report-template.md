# Glossary report template

The glossary report holds these parts, in this order:

- _Added_: each new term.
- _Changed_: each term whose name or definition changed, with the old text.
- _Removed_: each term removed, with the gate and condition it failed, or the
  word `unused`.
- _Renamed_: each word replaced by a word with one reading. Give the new word,
  every usage in the evidence set, and a count of the usages elsewhere.
- _Facts to place_: each fact taken out of a definition, with the document and
  line that use it. The user places these.
- _Instructions_: the file the reference line was added to, or the reason no
  line was added. For a deleted glossary, the removed reference line and its
  file.
- _Disagreements_: every usage in another document that disagrees with the
  glossary, with its path and line and the change that settles it. Add the word
  `rewritten` when the `disambiguating-text` skill rewrote that document. Add
  the word `quoted` when the usage sits in a verbatim third-party excerpt.
